# Security policy

## Reporting a vulnerability

This is HEY Research Lab's GitHub profile: the README and the scripts that draw its pictures. If you find a security
issue here, or in anything HEY Research Lab publishes, report it privately through GitHub's "Report a vulnerability"
(Security → Advisories) on this repository, or email hi@heyresearch.xyz with a subject starting "Security". Do not open
a public issue. We aim to acknowledge within 3 working days. There is no bug bounty.

How we report issues we find in other projects, and how to ask us for a review:
[github.com/hey-research-lab/security](https://github.com/hey-research-lab/security).
